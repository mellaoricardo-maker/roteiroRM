# Lista de contas para o content-ideas-br

Uma @conta por linha, no começo da linha. O que vier depois é anotação livre.
Linhas que não começam com @ são ignoradas: use "> @conta" para estacionar uma conta.
Só contas Profissionais (Empresa ou Criador de conteúdo) podem ser lidas pela API;
as pessoais aparecem como "falha" no relatório.

Dica: 20–40 contas que postam com frequência e falam com um público parecido com o seu.
Número de seguidores importa pouco; confira se os Reels recentes delas têm views.
